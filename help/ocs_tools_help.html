Tools for Open CAD Studio

A collection of drawing tools. Type a command at the command line, or use the buttons on the Tools ribbon tab. Command names are not case sensitive.

Steal - import from another drawing

CommandWhat it does
STEALOpens the Steal window. Pick a source drawing (DXF or DWG) and import its layers, linetypes, text styles, dimension styles and blocks into the drawing you have open. One Undo step. Closing the window only hides it; STEAL brings it back.
  • Use the type list on the left to switch between layers, linetypes, text styles, dimension styles and blocks. The filter takes comma separated text; an entry with * or ? is a wildcard.
  • Items marked (exists) are skipped unless Overwrite is ticked (never for blocks).
  • Run STEAL from the drawing tab you want to import into. The log is in %TEMP%\ocs-tools.log.

Viewports

Select the viewport on a layout first, then run the command. Both commands only work on a layout tab, not on the Model tab.
CommandWhat it does
VPMViewport to model space: draws a closed polyline on layer VP (colour 41) in model space, along the area the viewport shows. A viewport clipped to a polyline follows that boundary (arcs become straight segments). Perspective viewports are not supported.
VPSIViewport scale information: prints VPSCALE = 1:N, with N = 1000 / (viewport height / view height), which assumes paper in mm and model in metres. With several viewports selected each is listed by number.

Xrefs

These work on the layer that has the same name as each xref.

CommandWhat it does
XFZFreeze the layer named like each xref. Xrefs with no such layer are listed.
XTWThaw those layers.
XFIXMove every xref reference that is not on its own layer onto the layer named like the xref (created if missing), then lock that layer.

Layers

These change every layer in one go. The current layer is always left alone.

CommandWhat it does
F*Freeze all layers.
O*Turn all layers off.
LOFTurn all layers off (same as O*).
LONTurn all layers on.
T*Thaw all layers.
A*Thaw and turn on all layers, then regenerate.
OLStart LAYER OFF (you name the layer).

Osnap, purge and units

CommandWhat it does
OERunning osnap: endpoint only.
OIRunning osnap: intersection only.
ONRunning osnap: none.
PUAMake layer 0 current and purge everything the host can purge. Registered applications and scales are not purged by Open CAD Studio.
PULIMake layer 0 current and purge unused linetypes.
PUBMake layer 0 current and purge unused blocks.
AHUnits for horizontal work: decimal, 3 places, decimal degrees, angles from 0 counter-clockwise.
AVUnits for vertical work: decimal, 3 places, degrees/minutes/seconds, angles from 90 clockwise.

Good to know

  • Every step of Steal is logged to %TEMP%\ocs-tools.log.
  • If an alias does nothing, the command line shows what the host refused.
  • The shortcuts that run several commands send each one separately and clear any command left waiting before the next.
